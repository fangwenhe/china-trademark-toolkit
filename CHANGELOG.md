# Changelog

- Initial public release.

- SEO pass on README: table of contents, 10-question FAQ targeting high-intent search queries, official references, badges.

### Notes
- Official figures (CNY 270/class online fee, 6–9 month timeline, 3-month opposition window, 15-day review window, 10-year term) should be re-verified against the latest CNIPA notices before relying on them for a filing.

## Maintenance policy

This repository is reviewed on a regular cadence:
- **Weekly:** check CNIPA announcements for fee/form/timeline changes; add or refine one FAQ/guide entry; update this file.
- **Monthly:** review repository traffic and search terms, expand the dataset, and cross-link related China-IP resources.

If you spot an outdated figure, please open an issue — corrections are very welcome.
